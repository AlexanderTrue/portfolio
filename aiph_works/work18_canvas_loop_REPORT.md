# Work 18 — Release visual для музыканта (анимированная обложка + кинетическая типографика)

## Продукт
Релиз-кит для музыканта: анимированная обложка трека 10.125 с (бесшовный луп) с кинетической типографикой,
бит-синхронным свечением и собственным лоу-фай хаус фрагментом. Всё локально: SDXL арт → Wan I2V оживление →
композит типографики → мукс.
Вертикаль 720x1280 (9:16, Canvas) + квадрат 1:1 + статичная обложка с текстом.

## Арт-дирекция (по разбору с заказчиком: v2 «горы+луна» — клише, работу пересобрали)
- Направление: **ризо-постер** — плоские органические формы, burnt orange + deep teal на кремовой бумаге,
  зерно печати, halftone-точки, свисс-композиция. SDXL base, 32 шага dpmpp_2m karras cfg 6.5, 832x1216.
- Из 6 кандидатов (ризо ×2, y2k-хром ×2, брутализм ×2) выбран riso_00002: чистый верх под типографику,
  крупные формы читаются в моушне, ни одного «типового AI-пейзажа».
- Промт: `risograph poster art, abstract composition of overlapping organic shapes, burnt orange and deep teal inks on off-white paper, heavy grain texture, halftone dots, bold minimal swiss layout, sun-bleached paper, subtle misregistration, no text, no letters`

## Моушн (Wan 2.2 14B I2V fp8 + Lightning 4+4, cfg 1.0, 81 кадр, 17.5 мин)
- Промт: `abstract risograph poster shapes slowly drifting and rotating, overlapping circles gently breathing, subtle parallax between paper texture layers, halftone dots shimmering very softly, minimal elegant flat graphic motion, smooth continuous loop, no people, no text`
- Пинг-понг forward+reverse → 162 кадра = 10.125 c, стыка нет математически; идентичность форм проверена по стоп-кадрам

## Кинетическая типографика (новый навык в портфолио)
- Bebas Neue (OFL), имя артиста `MIRA VEY` (тёмно-бирюзовая краска #1E3A37) + название `HALF LIGHT`
  (акцентный оранжевый #E8641E) + тонкая акцентная линейка
- Появления привязаны к сетке бита: имя на 2-й бит (slide-up + fade), название на 4-й бит; дальше текст живёт весь луп
- Бит-пульс: деликатный glow всей картинки на пике каждого бита (sin^8 огибающая, амплитуда 3.5%)
- Мягкий верхний градиент-подклад для читаемости; кадр-композит в `tts\vo\gen_work18_type.py` (PIL, 162 кадра)

## Музыка (v3): лоу-фай хаус, 118.5 BPM
- Софт-кик 4/4, свингованный оффбит-шейкер, тёплые e-piano стабы (Dm9 → B♭maj7 → Fmaj7 → Cadd9), саб-корни, винильный треск
- Сэмпл-точный луп: 486000 сэмплов @ 48 кГц = ровно 10.125 c; все частоты квантованы на сетку целых циклов → ноль клика на стыке
- Намеренно другой язык, чем ритм-тех Work 19 (142 BPM, агрессивный синтетика) — замечание про однотипность музыки закрыто
- ffprobe: видео и аудио демо ×2 = 20.271 c — стык бесшовен в обоих потоках
